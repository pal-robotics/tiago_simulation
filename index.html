Integrating RTAB-Map with TIAGo Robot

A Comprehensive Guide to 3D SLAM and Navigation in ROS 2 Humble

RTAB-Map and TIAGo Integration Overview

This guide will walk you through integrating RTAB-Map, a powerful SLAM solution, with the TIAGo robot in ROS 2 Humble. RTAB-Map (Real-Time Appearance-Based Mapping) is a RGB-D Graph SLAM approach that creates detailed 3D maps of environments.

TIAGo Robot

Mobile base with RGB-D camera and LiDAR

RTAB-Map

3D SLAM processing sensor data

Navigation Stack

Path planning and obstacle avoidance

Why Use RTAB-Map with TIAGo?

TIAGo's sensor suite (RGB-D camera and LiDAR) is ideal for RTAB-Map's capabilities:

  • 3D Mapping: Create detailed volumetric maps of environments
  • Loop Closure Detection: Robust recognition of previously visited locations
  • Multi-Session Mapping: Extend maps across multiple sessions
  • Localization: Precise position estimation in known environments

Tip: RTAB-Map can process data from both RGB-D cameras and LiDAR simultaneously, creating more robust maps than using either sensor alone.

Setting Up TIAGo Simulation

Install Dependencies

Start by installing required tools:

Terminal Commands 
sudo apt-get update
sudo apt-get install git python3-vcstool \
    python3-rosdep python3-colcon-common-extensions

Create Workspace and Import TIAGo Packages

Set up the TIAGo workspace and import the necessary repositories:

Terminal Commands 
mkdir -p ~/tiago_public_ws/src
cd ~/tiago_public_ws
vcs import --input https://raw.githubusercontent.com/pal-robotics/tiago_tutorials/humble-devel/tiago_public.repos src

Resolve Dependencies and Build

Install dependencies and build the workspace:

Terminal Commands 
sudo rosdep init
rosdep update
rosdep install --from-paths src -y --ignore-src

source /opt/ros/humble/setup.bash
colcon build --symlink-install
source ~/tiago_public_ws/install/setup.bash

Launch TIAGo in Simulation

Test your setup by launching TIAGo in Gazebo:

Terminal Commands

ros2 launch tiago_gazebo tiago_gazebo.launch.py is_public_sim:=True

# With PAL office world
ros2 launch tiago_gazebo tiago_gazebo.launch.py \
  is_public_sim:=True world_name:=pal_office

# With navigation
ros2 launch tiago_gazebo tiago_gazebo.launch.py \
  navigation:=True is_public_sim:=True

Verification: After launching, test robot movement:

Terminal Commands 
ros2 topic pub /mobile_base_controller/cmd_vel_unstamped \

Installing RTAB-Map for ROS 2

Clone RTAB-Map Repositories

Navigate to your workspace and clone the required repositories:

Terminal Commands 
cd ~/tiago_public_ws/src

# Clone core library
git clone https://github.com/introlab/rtabmap.git src/rtabmap

# Clone ROS 2 wrapper (humble branch)
git clone --branch humble https://github.com/introlab/rtabmap_ros.git src/rtabmap_ros

Install Dependencies and Build

Resolve dependencies and build RTAB-Map:

Terminal Commands 
rosdep update
rosdep install --from-paths src --ignore-src -r -y

# Optimize build for performance
export MAKEFLAGS="-j6"  # Adjust based on your CPU cores

# Build with release flags
colcon build --symlink-install --cmake-args -DCMAKE_BUILD_TYPE=Release

Note: Building RTAB-Map requires significant RAM (at least 16GB recommended). If you encounter memory issues, remove the MAKEFLAGS export.

Integrating RTAB-Map with TIAGo

Launch TIAGo with Navigation

Start the TIAGo simulation with navigation enabled:

Terminal Commands 
ros2 launch tiago_gazebo tiago_gazebo.launch.py \
  navigation:=True is_public_sim:=True

Disable AMCL

RTAB-Map will replace AMCL for localization. Create a script to stop AMCL:

kill_amcl.sh 
#!/bin/bash

# Find AMCL process
PID=$(ps aux | grep '[a]mcl' | awk '{print $2}')

if [ -z "$PID" ]; then
  echo "AMCL process not found."
  exit 1
fi

echo "Stopping AMCL (PID: $PID)"
kill $PID

# Wait for shutdown
sleep 2

# Force kill if still running
if ps -p $PID > /dev/null; then
  echo "Force killing AMCL..."
  kill -9 $PID
fi

echo "AMCL stopped"

Make the script executable and run it:

Terminal Commands 
chmod +x kill_amcl.sh
./kill_amcl.sh

Launch RTAB-Map with TIAGo

Start RTAB-Map configured for TIAGo's sensors:

Terminal Commands 
ros2 launch tiago_gazebo tiago_rtabmap.launch.py

Understanding Remappings: RTAB-Map needs to know which topics to listen to. The TIAGo-specific remappings are critical:

  • RGB Camera: /head_front_camera/rgb/image_raw
  • Depth Camera: /head_front_camera/depth/image_raw
  • LiDAR: /scan_raw
  • Odometry: /mobile_base_controller/odom

Key Configuration Considerations

For successful integration, pay attention to:

TF Frames: Ensure consistency between:

  • base_footprint (TIAGo's base frame)
  • camera_link (RGB-D sensor frame)
  • base_scan (LiDAR frame)

Parameter Tuning: Adjust these RTAB-Map parameters for TIAGo:

  • Reg/Strategy: Set to 1 (Vis+ICP)
  • RGBD/NeighborLinkRefining: True
  • Grid/RangeMin: 0.2 (filter close points)

RTAB-Map Launch File for TIAGo

Custom Launch File

Create a launch file that configures RTAB-Map specifically for TIAGo:

tiago_rtabmap.launch.py 
from launch import LaunchDescription
from launch.actions import DeclareLaunchArgument
from launch.substitutions import LaunchConfiguration
from launch.conditions import IfCondition, UnlessCondition
from launch_ros.actions import Node
import os
from ament_index_python.packages import get_package_share_directory

def generate_launch_description():
    use_sim_time = LaunchConfiguration('use_sim_time')
    qos = LaunchConfiguration('qos')
    localization = LaunchConfiguration('localization')
    base_frame = 'base_footprint'  # TIAGo's base frame

    parameters = {
        'frame_id': base_frame,
        'use_sim_time': use_sim_time,
        'subscribe_depth': True,
        'subscribe_rgb': True,
        'subscribe_scan': True,
        'subscribe_scan_cloud': True,
        'approx_sync': True,
        'use_action_for_goal': True,
        'qos_scan': qos,
        'qos_imu': qos,
        'Reg/Strategy': '1',           # Vis+ICP registration
        'Reg/Force3DoF': 'true',        # 3DoF for ground robots
        'RGBD/NeighborLinkRefining': 'True',
        'Grid/RangeMin': '0.2',         # Min range for points
        'Optimizer/GravitySigma': '0'   # Ignore gravity for ground robots
    }

    # Remap to TIAGo's topics
    remappings = [
        ('rgb/image', '/head_front_camera/rgb/image_raw'),
        ('rgb/camera_info', '/head_front_camera/rgb/camera_info'),
        ('depth/image', '/head_front_camera/depth/image_raw'),
        ('depth/camera_info', '/head_front_camera/depth/camera_info'),
        ('rgbd_image', '/head_front_camera/rgbd/image'),
        ('depth/points', '/head_front_camera/depth/points'),
        ('scan', '/scan_raw'),
        ('odom', '/mobile_base_controller/odom'),
    ]

    rviz_config_dir = os.path.join(
        get_package_share_directory('rtabmap_ros'),
        'launch', 'rtabmap.rviz'
    )

    return LaunchDescription([
        DeclareLaunchArgument('use_sim_time', default_value='true'),
        DeclareLaunchArgument('qos', default_value='2'),
        DeclareLaunchArgument('localization', default_value='false'),
        
        # SLAM Node
        Node(
            condition=UnlessCondition(localization),
            package='rtabmap_slam', executable='rtabmap', 
            output='screen', parameters=[parameters],
            remappings=remappings, arguments=['-d']
        ),
        
        # Localization Node
        Node(
            condition=IfCondition(localization),
            package='rtabmap_slam', executable='rtabmap', 
            output='screen', parameters=[parameters, {
                'Mem/IncrementalMemory': 'False',
                'Mem/InitWMWithAllNodes': 'True'
            }], remappings=remappings
        ),
        
        # Visualization
        Node(
            package='rtabmap_viz', executable='rtabmap_viz', 
            output='screen', parameters=[parameters],
            remappings=remappings
        ),
        
        # RViz
        Node(
            package='rviz2', executable='rviz2', output='screen',
            name='rviz2', arguments=['-d', rviz_config_dir],
            parameters=[{'use_sim_time': use_sim_time}]
        ),
    ])

Key Configuration Notes:

  • use_sim_time: Set to 'true' for simulation
  • subscribe_scan_cloud: Enables LiDAR point cloud processing
  • Reg/Strategy 1: Combines visual and ICP registration
  • Reg/Force3DoF: Constraint for ground robots

Troubleshooting Common Issues

No Map Appearing in RViz

Possible causes and solutions:

  • TF Errors: Check frame transformations with ros2 run tf2_tools view_frames.py
  • Topic Remapping: Verify remappings match actual topics
  • Camera Issues: Ensure RGB and depth images are being published

Poor Mapping Quality

Improve mapping with these adjustments:

Parameter Adjustments 
# Increase feature detection
'Kp/DetectorStrategy': '6'  # Use GFTT + BRIEF

# Reduce minimum visual features for loop closure
'Vis/MinInliers': '15'

# Increase loop closure detection radius
'RGBD/ProximityPathMaxNeighbors': '50'

High CPU Usage

Optimize performance with these settings:

Performance Parameters 
# Reduce map update rate
'Rtabmap/DetectionRate': '2'  # Hz

# Limit memory usage
'Mem/STMSize': '30'  # Maximum stored locations

# Disable visual word generation
'Mem/IncrementalMemory': 'false'  # For localization mode

Common Error Messages

"Could not get camera info"

Solution: Verify camera_info topics are being published and remapped correctly.

"No matching device found"

Solution: Ensure Gazebo plugins for cameras are properly loaded.

"Transform failed" between frames

Solution: Check static transforms and URDF configuration.
